# Rove design

How to build Rove's interface with these tokens, for anyone writing Rove UI, people and coding agents alike. The [token reference](#colour) at the end lists every value; [`docs/rationale.md`](docs/rationale.md) explains why they are what they are.

## Setup

```css
@import '@swiftsolve/rove-design/tokens.css';
```

Dark is the default, on `:root`. Add the `theme-light` class to the root element for Light. Every token has both values, so a screen that only uses tokens themes itself.

## Rules

- **Use a token, never a raw value.** No hex colours, no pixel gaps, no font sizes typed by hand. If nothing fits, the design needs a new token in Figma, not a one-off in code.
- **Name by job, not by look.** Pick `--bg-panel` because it's a card, not because it's the right grey. The Palette shades (`gray/850`) aren't CSS variables, on purpose.

### Surfaces

- Backgrounds are an elevation ladder: `--bg-app` (window) → `--bg-chrome` (title bar, rail) → `--bg-shell` (behind the cards) → `--bg-panel` (cards) → `--bg-raised` (menus, tooltips). `--bg-inset` is for sunken bands and secondary buttons, `--bg-hover` for hovered rows and buttons, `--bg-scrim` behind dialogs.
- Cards get depth from `--shadow-panel` and a `--border-hairline-top` highlight, not hard outlines. Menus and tooltips use `--shadow-raised` on `--bg-raised`.
- Hairlines are `--border-default`; `--border-strong` is for a line that must stand out more.
- For hovers, chips and tracks on a surface, use the `--fill-*` overlays. They flip with the theme, so they stay visible on both.

### Text and icons

- `--text-primary` for content, `--text-secondary` for supporting lines, `--text-tertiary` for the quietest text and for icons by default.
- On a solid fill (accent or Stop button), labels and icons use `--text-on-fill`.
- On `--accent-muted` (a selected item, a tinted button), text uses `--text-accent`.

### Accent and buttons

- `--accent-default` is for accent text, icons and lines. It's too light under a white label.
- Filled buttons use `--accent-fill`, hovering to `--accent-fill-hover`. Hovers deepen, never lighten, so the white label keeps its contrast.
- The Stop button uses `--status-negative-fill` and `--status-negative-fill-hover`.

### Status

- `--status-*` (positive, good, warning, poor, negative) colour icons, bars and dots.
- Words in a status colour use `--text-*` of the same name. The `--status-*` shades are too light for text in Light mode.
- Download and upload in charts are `--series-down` and `--series-up`.

### Tints and opacity

Tints are a colour mixed with transparent at one of the shared strengths, so a tinted tile reads the same everywhere:

```css
background: color-mix(in srgb, var(--status-positive) var(--opacity-tint-md), transparent);
```

Disabled controls use `--opacity-disabled`.

### Spacing and shape

- Every gap, padding and margin is a `--spacing-*` step.
- Cards use `--section-padding` on every side. The rail and the content column share the side inset `--spacing-11`.
- Corners are `--radius-*`. `--radius-md` is for nav items and the page-header chip, a step rounder than `--radius-sm`; `--radius-full` makes pills.

### Type

- Set text with a text style's four `--type-<style>-*` variables, not a font size alone. Each style's use and matching code class is in [Text styles](#text-styles).
- Numbers that are data (speeds, totals, chart labels) use the Questrial styles (`metric-*`, `value`, `chart-label`); everything else is Inter.

### Focus and motion

- Keyboard focus is `outline: var(--focus-outline)` with `outline-offset: var(--focus-offset)`. Rows flush with a card's edge draw it inside instead, with `--focus-inset`.
- Animate with `--ease-out` (or `--ease-in-out`) over `--duration-fast` or `--duration-normal`.

## Changing the design

Figma is the source of truth. Change a token in the Rove Design System Figma file, export it with the plugin in `figma-plugin/` into `src/figma/`, then run `npm run build` (see the [README](README.md#update-the-tokens)). Don't edit `tokens.css`, `tokens/` or the values in `src/figma/` by hand. What Figma can't hold (shadows, layout, motion) lives in `src/code-tokens.json`.
